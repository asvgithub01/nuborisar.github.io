# Jarvis Agent 0.3.2

- Consola de terminal ligera con estado local tipado.
- Actualizacion de Codex CLI solo cuando el agente esta en reposo, con verificacion y rollback.
- Canal de autoactualizacion del agente mediante manifest HTTPS y artefactos SHA-256.
- Paquetes publicos genericos para Windows x64 y macOS Apple Silicon, sin credenciales.

La primera instalacion de 0.3.0 es manual. Las versiones posteriores pueden actualizarse
automaticamente desde update/stable.json.
